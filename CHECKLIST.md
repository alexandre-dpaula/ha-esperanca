# ✅ Checklist de Lançamento

## 📋 Antes do Deploy

### Conteúdo
- [ ] Revisar todos os textos em português
- [ ] Verificar se há erros de digitação
- [ ] Validar que as frases transmitem esperança e acolhimento
- [ ] Testar se a mensagem ressoa emocionalmente

### Personalização
- [ ] Substituir imagens do Unsplash por imagens próprias (opcional)
- [ ] Atualizar número de WhatsApp no modal de contato
- [ ] Configurar e-mail real de contato
- [ ] Ajustar cores se necessário (manter identidade visual)

### Técnico
- [ ] Testar todas as seções no navegador
- [ ] Verificar se animações funcionam suavemente
- [ ] Confirmar que ícones Lucide aparecem
- [ ] Testar modais (abrir e fechar)
- [ ] Validar formulário de oração
- [ ] Verificar responsividade mobile (iPhone, Android)
- [ ] Testar em diferentes navegadores (Chrome, Safari, Firefox)

---

## 🚀 Deploy

### Vercel
- [ ] Instalar Vercel CLI: `npm install -g vercel`
- [ ] Fazer login: `vercel login`
- [ ] Deploy inicial: `vercel`
- [ ] Deploy produção: `vercel --prod`
- [ ] Anotar URL gerada

### GitHub (Opcional)
- [ ] Criar repositório
- [ ] Push inicial: `git push -u origin main`
- [ ] Conectar com Vercel para deploy automático

---

## 🎯 Após Deploy

### Teste em Produção
- [ ] Acessar URL de produção
- [ ] Testar em dispositivo mobile real
- [ ] Compartilhar com 2-3 pessoas para feedback
- [ ] Verificar tempo de carregamento (Google PageSpeed)
- [ ] Testar formulários e envio de dados

### Integrações
- [ ] Configurar serviço de formulário (Formspree, EmailJS, etc.)
- [ ] Testar envio de pedido de oração
- [ ] Verificar se notificações estão chegando
- [ ] Validar links de WhatsApp e e-mail

### Monitoramento
- [ ] Configurar Google Analytics (se quiser métricas)
- [ ] Configurar Vercel Analytics
- [ ] Criar alerta de uptime (UptimeRobot - grátis)

---

## 📱 QR Code

### Criação
- [ ] Gerar QR Code: [qr-code-generator.com](https://www.qr-code-generator.com/)
- [ ] Apontar para: `https://seu-projeto.vercel.app`
- [ ] Testar QR Code com smartphone
- [ ] Salvar imagem em alta qualidade (PNG ou SVG)

### Design do Adesivo
- [ ] Criar layout do adesivo com QR Code
- [ ] Adicionar frase: "Escaneie para uma mensagem especial"
- [ ] Incluir logo ou símbolo (cruz, luz, planta, etc.)
- [ ] Manter design minimalista e elegante

### Impressão
- [ ] Escolher material (papel adesivo, vinil, etc.)
- [ ] Definir tamanho (sugestão: 5x5cm ou 7x7cm)
- [ ] Imprimir teste antes da tiragem final
- [ ] Validar legibilidade do QR Code impresso

---

## 📖 Bíblias

### Preparação
- [ ] Definir quantidade de Bíblias
- [ ] Escolher tradução (NVI, ARA, NAA, etc.)
- [ ] Comprar ou receber doações
- [ ] Preparar embalagem (se houver)

### Aplicação do QR Code
- [ ] Colar adesivo na contracapa ou primeira página
- [ ] Garantir que está bem fixado
- [ ] Testar leitura do QR após colado
- [ ] Adicionar cartão de boas-vindas (opcional)

### Distribuição
- [ ] Definir estratégia de distribuição:
  - [ ] Entrega pessoal em locais públicos
  - [ ] Parceria com igrejas
  - [ ] Deixar em lugares estratégicos (cafés, bibliotecas, etc.)
  - [ ] Envio pelos correios
- [ ] Preparar equipe de distribuição
- [ ] Treinar sobre abordagem acolhedora
